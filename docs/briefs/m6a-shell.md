## Part 3: haptics (`src/app/haptics.ts`)
A pure mapping from sim and game events to vibration patterns plus a thin `navigator.vibrate` wrapper (feature-detected; silent no-op where missing, and off when the setting is off or the page is hidden). Patterns (milliseconds), tuned to be felt but short: hitch (a firm 18), release (10, gap 30, 22: the snap), each chain link beyond the first (one more short pulse per link, capped), land (8–30 scaled by impact), hop (6), grind start (a 12) and a light tick every 150 ms while grinding, wall hit (25), bail (60, gap 40, 60), bounce (15), denied (8, gap 60, 8), segment inked (12, gap 40, 12), line complete (a longer roll), errand/conductor/secret events if those event types exist in `GameEvent` (map by name; unknown events do nothing). Rate-limit so patterns never queue up (a new pattern replaces a running one only if it is more important: give each a priority). The mapping function is pure and unit-tested: events in, at most one pattern out per frame.
